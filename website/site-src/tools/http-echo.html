More endpoints

  

    
ANY /__public/echo/**
Describes the request: method, path, query, headers, body, parsed JSON or form, and size. Bodies up to 1 MB.

    
GET /__public/headers
Just the request headers.

    
ANY /__public/status/{code}
Answers with that status, for example /__public/status/503.

    
ANY /__public/delay/{ms}
Answers after a delay of up to 10,000 ms, to test timeouts.
