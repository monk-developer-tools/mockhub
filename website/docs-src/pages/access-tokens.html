A personal access token lets a script, a CI job or an AI agent use MockHub as you, without your password. Send it as Authorization: Bearer mh_… to the API or the MCP server. Tokens only exist when sign-in is on. With sign-in off, the API and MCP work without one.

Create a token

Open your account (your name at the bottom of the sidebar), select Access tokens, then New token:

SettingWhat it does
NameWhere it's used, such as Claude Code on my laptop. The name appears in the audit log next to every change the token makes.
AccessThe most the token can do: viewer, editor, manager or admin. It never gets more than you have. An editor token used by a manager still can't change project settings, and a token gets nothing where you have no access.
ProjectsAll I can reach, or only the projects you tick. A scoped token can't see other projects, organisations or server settings. If you delete a project, it's removed from every token, and a token left with no projects is deleted.
ChangesApply directly, or Stage for review. See review mode.
Expires after7, 30, 90 days (the default), a year, or never.

MockHub shows the token once, with ready-to-paste setup for Claude Code, Cursor, Codex and Claude Desktop. It keeps only a SHA-256 fingerprint, so a lost token can't be recovered: revoke it and make a new one.

Treat a token like a password. Keep it in your agent's config or a CI secret, never in a repository. Prefer a short expiry, the lowest access that works and only the projects the job needs.

See and revoke tokens

The list shows each token's name, its first characters, access, projects, mode, when it was last used and when it expires. Select the bin to revoke one; anything using it stops working at once. Admins can revoke anyone's token through the API. A token can't create or revoke tokens, or change your password.

Tokens in the API

# call the API as yourself, from CI
curl -H "Authorization: Bearer $MOCKHUB_TOKEN" $HUB/__admin/mockhub/api/projects

# create a token (needs a normal sign-in, not a token)
curl -X POST -u alex:$PASSWORD $HUB/__admin/mockhub/api/auth/tokens \
  -d '{"name":"CI","role":"editor","projectIds":["58b5108a"],"mode":"direct","expiresInDays":30}'
EndpointPurpose
GET /auth/tokensyour tokens, newest first, without secrets
POST /auth/tokenscreate one: name, role, projectIds (empty means all), mode (direct or review), expiresInDays (7, 30, 90, 365 or 0 for never). The answer has the secret
DELETE /auth/tokens/{tokenId}revoke

A request with an expired, revoked or unknown token gets 401. A request outside the token's access or projects gets 403 with the reason.
