Many APIs answer at once and report the result later by calling you back. MockHub mocks both sides.

Then call. In a stub's Then call section, add one or more webhooks with a method, URL, headers, body and delay. They're sent after the stub answers. The URL, headers and body are templates, and Insert dynamic value lists what you can use:

In a webhookGives
{{jsonPath originalRequest.body '$.callbackUrl'}}a value from the request, here a callback URL to call
{{{originalRequest.body}}}, {{originalRequest.headers.X-Id}}, {{originalRequest.path.id}}the rest of the request
{{jsonPath originalResponse.body '$.id'}}, {{originalResponse.status}}the mock response the stub just sent
{{now}}, {{randomValue type='UUID'}}, {{fake 'Name.fullName'}}any other templating helper

Choose Forward incoming request to send the request as it arrived (method, headers and body) instead of a custom body.

Wait for callout. As the response type, Wait for callout calls the URL while the caller waits and answers with the target's status, headers and body. If the call fails, the caller gets 502 with the reason.

Callouts tab. Every callout shows up live with what was sent, the answer, the time it took and any error. On a failed one, Ask the assistant to fix it hands it to the AI assistant.

Catch all webhooks. On the Requests tab, this adds a low-priority stub that answers 200 to anything no other stub matched. Point a third-party webhook at <mock URL>/webhooks and inspect each call in the request history.

Calls to MockHub's own mock URLs always work. Private and local addresses are blocked unless an admin sets MOCKHUB_CALLOUT_ALLOW_PRIVATE=true. Webhooks are stored as mockhub-callout serve event listeners. WireMock's own webhook mappings still run, and they become mockhub-callout when you save them in the editor. The WireMock mappings export turns them back into webhook.

Tokens and retries. To call a service that needs an OAuth2 token or an API key, add a connection and pick it under Sign with. The same section sets retries for answers like 503.
