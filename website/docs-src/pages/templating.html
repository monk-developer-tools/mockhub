MockHub adds a few of its own: {{len x}} for the length of text or a list, {{{object id=1 name='Ada'}}} to build a JSON object, {{{json x}}} to write any value as JSON, {{toNumber x}} so a value lands in JSON without quotes, and {{default x 'fallback'}}. There are also helpers to sign and read JWTs and to validate requests.

Helpers with Beeceptor's names

Templates written for Beeceptor mostly work as they are. These helpers take the same arguments in the same order:

  • Flow: {{#switch x}}{{#case 'a'}}…{{/case}}{{#default}}…{{/default}}{{/switch}}, and {{#repeat 3}}…{{/repeat}} or {{#repeat 1 5}} for a random count, with commas between copies unless comma=false, @index and @total, up to 1,000.
  • Lists: sort (with a field and 'desc'), reverse, oneOf, someOf (a list, a minimum, a maximum and true for JSON), concat for text or lists, objectMerge, coalesce and jsonParse with an optional path like items.0.id.
  • Text and checks: padStart, padEnd, urlDecode, base64Decode, lowercase, uppercase, isNumber, isInteger and isDate.
  • Dates: {{dateAdd date '{days:3}' 'iso'}}, {{dateDiff start end 'days'}} and dateParse with 'unix', 'timestamp' or a pattern like 'DD-MM-YYYY'. Formats are Beeceptor's shorthands (iso, utc, short, long, unix, timestamp, us, eu, …) or day.js patterns, in UTC.

Two differences to know. (body 'x') is (jsonPath request.body '$.x') here, and WireMock's jsonPath gives empty text for a missing field, which coalesce keeps, as Beeceptor does for ""; use {{default (jsonPath request.body '$.x') 'fallback'}} for that. And three closing braces in a row, like {{/switch}}} at the end of a JSON object, read as a triple-stash, so put a space before the last }.

You don't need to remember these. Above the body, Insert dynamic value opens a searchable menu of every helper, grouped as request components, control flow, data manipulation, stateful helpers, comparison, string, arithmetic and date operators, array helpers, random values and Faker. A click inserts the helper at the cursor and turns templating on. See the WireMock templating reference for the full list.
