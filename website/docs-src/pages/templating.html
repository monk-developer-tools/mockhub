Turn on Response templating to build responses from the request:

HelperGives
{{request.path.id}}a path-template variable
{{request.query.page}}a query parameter
{{request.headers.X-Tenant}}a header
{{jsonPath request.body '$.email'}}a value from a JSON body
{{xPath request.body '//id/text()'}}a value from an XML/SOAP body
{{randomValue type='UUID'}}a random UUID (also ALPHANUMERIC, NUMERIC…)
{{randomInt lower=1 upper=100}}a random number
{{now offset='7 days' format='yyyy-MM-dd'}}dates
{{#if …}} {{#eq a 'b'}} {{#each …}}conditionals and loops

You don't need to remember these. Above the body, Insert dynamic value opens a searchable menu of every helper, grouped as request components, control flow, data manipulation, stateful helpers, comparison, string, arithmetic and date operators, array helpers, random values and Faker. A click inserts the helper at the cursor and turns templating on. See the WireMock templating reference for the full list.
