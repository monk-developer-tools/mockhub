OpenAPI 3 / Swagger 2 (JSON or YAML)One stub per operation. The response uses the spec's example, or sample data generated from the schema. Optionally strip a prefix such as /api/v1, and keep the document as the project's contract for drift checks.
WSDL 1.1See SOAP & WSDL.
SOAP requests (no WSDL)One stub per operation found, plus an endpoint for any other operation. See SOAP & WSDL.
GraphQL SDL or introspection JSONOne endpoint that answers from the schema. See GraphQL.
Protobuf descriptor set (.dsc)Serves the gRPC services in it, with one starter stub per method on request. Upload it under gRPC services in the same tab. See gRPC.
Postman collection (v2.0 or v2.1)See Postman collections.
WireMock mappingsA {"mappings": [...]} file, an array, or one stub. Exports from another project are re-rooted automatically.
WireMock folder (.zip)A zip of a folder with mappings and __files, at any depth. Every mapping file is imported, body files are copied into the project (sub-folders included) and bodyFileName is updated. Folders are kept, and ./ paths and file names built with templates keep working. Files a mapping needs but the zip lacks are listed. Limits: 20,000 entries, 10 MB per file, 200 MB in total.

Postman collections

In Postman, choose Export on the collection and keep Collection v2.1. Then upload the file under Postman collection in the project's Import / export tab. Version 1 collections are refused, with a hint to export again.

In the collectionIn MockHub
A saved example responseOne stub. It answers with the example's status, headers and body. When a request has several examples, each is named Request · Example.
A request with no saved exampleOne stub that answers 200 with an empty body. The import result lists it, so you can fill in the response.
FoldersStub folders, with nested names joined by /.
URL pathMatched on the path only. The host and {{baseUrl}} are dropped. :id and {{id}} segments become path parameters. Strip a prefix such as /api as with OpenAPI; requests outside it are left out and listed.
Query parametersMatched exactly. Disabled ones and ones whose value is a {{variable}} are not matched.
Raw JSON body (not GET)Matched as JSON, ignoring extra fields, so each example answers its own body.
Request descriptionThe stub's description.

Two examples that match exactly the same request keep only the first; the rest are listed in the result. One import makes at most 1,000 stubs. Over the API: POST /__admin/mockhub/api/projects/{id}/import/postman?stripPrefix=/api with the collection as the body.

Mock an OpenAPI file from a URL

Open Mock an OpenAPI URL in the sidebar and paste the address of an OpenAPI 3 or Swagger 2 file. MockHub downloads it, shows its title, version and number of operations, and creates a new project with one stub per operation. You need the editor role in a team.

RuleWhy
http and https only, up to 5 MBUp to 3 redirects are followed, and the download stops after 20 seconds.
No private or local addressesSo the server can't be used to read internal services. An admin can allow them with MOCKHUB_PLAYGROUND_ALLOW_PRIVATE=true, the same setting the playground uses. Every redirect is checked too.

A "Mock these APIs" button for your API docs

The same page builds a link and a badge for the file you entered. Put it in a README or on your API portal; readers who click it land on that page on your MockHub with the file filled in, sign in, and get their own mock project.

[![Mock these APIs](https://mocks.example.com/__admin/mockhub/ui/mock-these-apis.svg)](https://mocks.example.com/__admin/mockhub/ui/mock-these-apis?openapi=https%3A%2F%2Fapi.example.com%2Fopenapi.yaml)

The badge image needs no sign-in, so it shows on GitHub and in other docs. The link works on any MockHub server: change the host to your own.
