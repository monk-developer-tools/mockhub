Create a project, open it, and choose REST stub. Set the method and path, then the response status and body, and save. Click Send in the Try it panel to call it.

The form covers the common cases. Switch to JSON for anything else WireMock supports. This is the same stub as JSON, as sent through the API:

{
  "name": "Get payment",
  "request": { "method": "GET", "urlPathTemplate": "/payments/{id}" },
  "response": {
    "status": 200,
    "headers": { "Content-Type": "application/json" },
    "jsonBody": { "id": "{{request.path.id}}", "status": "PAID" },
    "transformers": ["response-template"]
  }
}

Not sure where to start? The template gallery button in the stub list has ready-made patterns for common cases.

Under Call it from your code, every stub has a snippet you can copy as cURL, HTTPie, JavaScript, Python, Java, C# or Apex. The request log offers the same for any request it captured.
