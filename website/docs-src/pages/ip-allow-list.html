To make a mock answer only your own network, for example a CI runner or the office VPN, add addresses in Settings → Runtime behaviour → IP allow list. One per line: single addresses like 203.0.113.7 or ranges like 10.0.0.0/8, IPv4 or IPv6 (2001:db8::/32), up to 100 entries. Host names aren't accepted, so nothing is looked up in DNS. Leave the list empty to allow everyone.

Calls from anywhere else get:

HTTP/1.1 403 Forbidden
Content-Type: application/json

{"error":"Calls from 198.51.100.4 aren't allowed for this mock"}

Behind a proxy or load balancer

MockHub checks the address the connection comes from. Behind a reverse proxy or a load balancer, that's the proxy's address. Add the proxy's range, or limit access at the proxy instead.

The allow list protects a mock from casual use. It isn't a replacement for an API key or a firewall.
