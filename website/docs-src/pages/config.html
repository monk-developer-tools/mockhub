Public tools

With MOCKHUB_PUBLIC_TOOLS=true, anyone can use these endpoints without signing in. They are off by default. When they are off, /__public/ is passed to your mocks like any other path.

EndpointWhat it does
ANY /__public/echo/**Answers with JSON that describes the request: method, path, query, headers, body, parsed JSON or form. Bodies up to 1 MB. Nothing is stored.
GET /__public/headersThe request headers
ANY /__public/status/{code}Answers with that status
ANY /__public/delay/{ms}Answers after the delay, up to 10,000 ms
POST /__public/binsCreates a webhook bin and returns its id and a private token
ANY /__public/bins/{id}/**Captured: the bin keeps the last 50 requests (bodies cut at 10 KB) and answers with its reply
GET /__public/inspect/{id}Lists captured requests; send the token as X-Bin-Token. Add ?after={seq} to get only newer ones. DELETE clears the bin.
GET|PUT /__public/inspect/{id}/responseReads or sets the bin's reply: {"status": 202, "contentType": "text/plain", "body": "ok"}, body up to 4 KB
POST /__public/renderRenders {"template": "...", "request": {"method", "url", "headers", "body"}} with the response-template engine and MockHub's helpers
POST /__public/fakeGenerates up to 100 records: {"count": 5, "fields": [{"name": "email", "expression": "Internet.emailAddress"}]}

Limits per client address: 120 requests a minute in total, 30 renders or fake-data calls a minute, and 10 new bins an hour. Over the limit the answer is 429 with Retry-After. Bins are kept in memory and deleted 24 hours after their last request; the server holds at most 200.

The render endpoint turns off helpers that read the server (systemValue, hostname), partials and assign. It also caps loops at 2,000 runs in total, sizes and ranges at 10,000, rendering time at 2 seconds and output at 256 KB. Behind a reverse proxy, MockHub takes the client address from X-Forwarded-For.
