Sign-in is off until the first user exists. Open Users and create an admin, or start with a break-glass account in MOCKHUB_USERS. Mock endpoints are never protected; only the UI and the admin API are.

MOCKHUB_USERS="root:change-me:admin"

An organisation is your company or department. It holds teams, and each team owns its projects. Add people under Teams & people → Add people in three choices: who, where (the whole organisation or only some teams) and what they can do. Pick an organisation with the switcher at the top of the sidebar. Teams live inside an organisation and own its projects. Every organisation has a General team, and projects from before teams existed move there. People get a role in single teams, an organisation-wide role that applies to every team, or both; the higher role wins, and team members only see their own teams' projects. Moving a project to another team or organisation doesn't change its mock URL. See the teams tutorial for a walk-through.

Only members see a team's projects. Someone in the Checkout team can't open, change or delete the Search team's projects, stubs, request log or activity, and the admin API answers 403.

A team is open to the whole organisation by default: an organisation-wide role, or a server-wide viewer or editor role, applies to it too. A team manager can make it restricted under the team's Settings → Who can see its projects. Then only the people added to that team see its projects, with their team role; organisation managers and server admins keep their access so they can still run it. From a script, PUT /__admin/mockhub/api/orgs/{orgId}/teams/{teamId} with {"restricted": true}.

Mock URLs are different: apps and tests call them without signing in, so turn on an API key when a project's mocks must stay private.

Secrets stay with admins. Only admins create organisations, see or change a project's API key, and configure the AI assistant, single sign-on and backups. Managers and editors see X-API-Key · set; Try it, code snippets and Postman / Bruno exports use a {{apiKey}} placeholder, which Postman and Bruno mark as a secret variable to fill in. Existing owner memberships and SSO mappings become manager automatically.
