After signing in, select New mock at the top of the sidebar, or a card on the dashboard. The page has a card for every way to start, in the same three groups as this website's menus: Mock servers, Tools and Service virtualization. Each card opens one screen: give it what you have, choose where it goes, and select Create mock. You land on the project with a Your mock is ready panel showing its address and commands that call it.

What each card makes

CardYou give itYou get
OpenAPI or SwaggerA file, its URL or pasted textOne stub per operation with example answers. Optionally strip a prefix and keep the spec as the contract.
SOAP from WSDLA WSDL 1.1 file or textA stub per operation, the ?wsdl endpoint and a fault for any other operation. See SOAP & WSDL.
GraphQLSDL or an introspection resultA /graphql endpoint that answers every query and mutation. See GraphQL.
gRPCA .proto fileThe services, with a starter stub per method. See gRPC.
CRUD REST API, CSV to REST APIA resource name and records as JSON or CSV, or noneA REST resource that saves records. See CRUD resources.
JSON or XML answerThe answer, method, path, status and content typeOne stub that sends that answer.
Webhook testingReceive: a path. Answer, then call back: a path, your URL and a delay.A receiver that answers 200 and records every webhook in Requests, or a stub that calls your service back. See Webhooks.
HTTP traffic monitoring, Local tunnelThe service's address, or a tunnel name for a service on your machineA project that forwards every call and records it. Add stubs later to replace one answer at a time. See Proxy and Local tunnel.
HTTP echoA pathAn endpoint that answers with the request it received. See Echo.
Postman collectionA v2.0 or v2.1 fileOne stub per saved example. See Postman collections.
Describe it to AIA sentence or two about the APIA chat with the assistant, which drafts the stubs for you to review. Shown when AI is set up.

The other cards open what already exists: the ready-made examples and vendor sandboxes, an empty project, the test data and 2FA tools, Teams & people, and the docs on contract checks and API tests in CI. Every card with a file has Use a sample, so you can try it in one click.

Where it goes

Your roleWhat you can do
Manager or adminCreate a new project, named from the file or the service, in one of your teams, or add to a project you edit.
EditorAdd to a project you edit. Creating projects needs the manager role in a team.
ViewerLook at projects. The page says to ask a manager of your team for the editor role.

Mistakes, such as a broken spec or invalid JSON, are shown on the screen before anything is created. If a new project can't be filled, for example because the spec fails to import, it is removed again, so no empty project is left behind. The command palette (⌘ K or Ctrl K) has New mock: … for every card.
