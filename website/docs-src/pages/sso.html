1. In the Entra admin centre, open App registrations → New registration. Choose Web and paste the redirect URI shown under MockHub → Single sign-on: https://<host>/__admin/mockhub/api/auth/sso/azure/callback.
  2. Copy the Application (client) ID and Directory (tenant) ID. Under Certificates & secrets, create a client secret and copy its value.
  3. Optional: add a groups claim under Token configuration, or define App roles.
  4. Paste the values into MockHub and choose Test connection. Then set the allowed domains, the organisation and role every new user gets, and mappings from group IDs or app roles to roles. Turn it on and save.

MockHub uses the authorisation code flow with PKCE and checks the ID token's signature, issuer, audience, expiry and nonce. Roles from groups are refreshed at every sign-in; roles set by hand are kept. Set MOCKHUB_PUBLIC_URL behind a proxy so the redirect URI matches. Supply the secret with MOCKHUB_SSO_CLIENT_SECRET if you keep it in a secret store.
