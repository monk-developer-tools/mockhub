In a project's Settings, turn on Require an API key and choose the header (default X-API-Key) and the key. Every call under the project's base path must then send it. Calls without the right key get a 401: JSON for REST, a SOAP 1.1 or 1.2 fault for SOAP. OPTIONS preflights and ?wsdl stay open. Only admins can see, set or change the key. For admins, Try it, code snippets and the Postman and Bruno exports send the key automatically; everyone else sees X-API-Key · set and gets a {{apiKey}} placeholder to fill in with the key an admin shares.
