MockHub records every change: who created, changed, turned off or deleted a project, stub, team, person or setting, and when. A deleted stub keeps the name it had, so you can still tell what was removed. Open a project's Activity tab to see its history. Admins see every change under Audit log; organisation and team managers see the changes in what they own. Each entry shows the exact time to the second in your time zone, plus how long ago. Select an entry for the full date, the UTC timestamp, who did it and the entry ID. Filter by created, changed or deleted, by person and by the last 24 hours, 7 days or 30 days, and download what you see as CSV. Failed attempts, such as a refused delete, aren't recorded. A change made with an access token, for example by an agent over MCP, shows the token name: Alex Morgan via token “Claude Code”. Creating and revoking tokens is recorded too, and so are taking, uploading, restoring and deleting snapshots and pulling from another project.

Entries are kept for 90 days, then removed from disk to save space. Change this with MOCKHUB_AUDIT_RETENTION_DAYS. Each entry is also printed to standard output as one line, so your log platform keeps its own copy:

2026-03-10T09:14:02.511Z INFO audit - Sam Patel: Deleted stub “GET /orders” {"actor":"Sam Patel","action":"deleted","target":"stub",...}

Each user also has a server role. Viewer everywhere and editor everywhere apply to every organisation. Admin also manages users, single sign-on, backups and the native WireMock API. Changing a password or disabling a user signs out that user's other sessions.
