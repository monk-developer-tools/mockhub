TermMeaning
ProjectThe mocks of one service. It owns a base path such as /payment-service, so its mock URL is https://your-host/payment-service.
Root projectAt most one project per server can answer at the root: its stubs match without a base path, exactly like a plain WireMock server. Paths that start with another project's base path still go to that project.
StubA rule: when a request matches, send this response. Stubs are plain WireMock stub mappings, edited relative to the project's base path.
PriorityWhen several stubs match, the lowest number wins (1 is highest, the default is 5). Use it for "specific case first, generic fallback last".
ScenarioA named state machine that lets the same request get different answers over time.
